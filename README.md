# Куда писать в Неакторе

Путеводитель для сотрудников ПСК Геодор: по ситуации подсказывает, в какой блок Неактора (neaktor.pskgeodor.ru) завести задачу и что выбрать в форме.

Вся страница — один файл `index.html`, без сборки и внешних библиотек (шрифт Open Sans грузится с Google Fonts).

## Публикация на GitHub Pages

1. Создать репозиторий, например `neaktor-guide`, и загрузить в корень `index.html` (Add file → Upload files → Commit).
2. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты страница появится по адресу `https://<аккаунт>.github.io/neaktor-guide/`.
4. Этот адрес добавить пунктом «Куда писать?» в верхнее меню Неактора.

Сайт на GitHub Pages открыт всем, у кого есть адрес. На странице только названия процессов и ссылки на Неактор; сами ссылки без входа в Неактор не открываются. Поисковикам индексировать страницу запрещено (`noindex`).

## Как обновлять

Данные лежат в начале `<script>` в `index.html`:

- `P` — блоки Неактора: код проекта → название и id статьи в wiki;
- `CATS` — темы в левой колонке;
- `S` — ситуации: `[тема, что нужно, код блока, что выбрать в форме, слова для поиска, подсказка, проверено (1/0)]`;
- `POPULAR` — кнопки «Часто ищут».

Чтобы добавить ситуацию, скопируйте строку в `S` и поменяйте значения. Если код блока новый, сначала добавьте его в `P`. Правку можно сделать прямо на github.com (значок карандаша у файла); через 1–2 минуты после коммита страница обновится.

## Проверка формулировок

Адрес с `#review` на конце подсвечивает ситуации, которые составлены по названию процесса и ещё не подтверждены владельцем. После проверки поставьте в строке последнее значение `1`.
